# JumpLab AI

開啟 `index.html` 即可使用。

## 使用流程

1. 勾選安全確認。
2. 選擇 CMJ／SJ／DJ 與影片 FPS。
3. 匯入側面跳躍影片。
4. 按「載入姿態 AI」；瀏覽器會載入 MediaPipe Pose Landmarker。
5. 按「AI 偵測 T／L」取得初始起跳與落地影格。
6. 在逐格時間軸複核，必要時用「標記 T 起跳」與「標記 L 落地」修正。
7. 儲存試跳或列印／另存 PDF。

## 注意

- 姿態模型、影片與分析結果在瀏覽器端處理；模型第一次載入需要網路。
- 若直接用 `file://` 開啟時瀏覽器阻擋遠端模型，請用 HTTPS 網站或本機 HTTPS server 開啟。
- AI 事件偵測是初始估計，請務必人工逐格確認，尤其是遮擋、寬鬆衣物、低畫質或非正側面影片。
